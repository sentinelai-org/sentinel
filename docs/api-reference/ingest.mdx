---
title: "Document Ingestion"
description: "Submit documents for asynchronous background chunking, embedding, and indexing via Redis Streams"
---

Sentinel processes document indexing asynchronously via Redis Streams (`sentinel:stream:ingest_jobs`). The API gateway accepts document batches immediately (`HTTP 201 Created`) without blocking HTTP workers during heavy embedding calculations.

---

## 1. Submit Ingestion Job

`POST /v1/ingest/jobs`

### Request Body

<ParamField body="documents" type="array" required>
  List of document objects to be chunked and indexed.
  <Expandable title="Document Object Properties">
    <ParamField body="content" type="string" required>
      Raw text or markdown content of the document.
    </ParamField>
    <ParamField body="source" type="string">
      Source identifier, filename, or relative file path (default: `api_upload`).
    </ParamField>
    <ParamField body="metadata" type="object">
      Arbitrary key-value metadata tags attached to chunks in Qdrant (e.g. `{"department": "SRE", "tenant_id": "org_1"}`).
    </ParamField>
  </Expandable>
</ParamField>

### Request Example

```bash
curl -X POST http://localhost:8000/v1/ingest/jobs \
  -H "Authorization: Bearer sk-live-prod-key" \
  -H "Content-Type: application/json" \
  -d '{
    "documents": [
      {
        "content": "# Production Runbook\n\nIf redis latency exceeds 50ms, run failover command: redis-cli failover",
        "source": "runbooks/redis.md",
        "metadata": {"team": "infrastructure"}
      }
    ]
  }'
```

### Response Example (201 Created)

```json
{
  "job_id": "job_01j7q3b2x1k5m8n9",
  "status": "queued",
  "total_documents": 1,
  "created_at": "2026-10-19T04:20:00Z"
}
```

## 2. Check Ingestion Job Status

`GET /v1/ingest/jobs/{job_id}`

### Request Example

```bash
curl -X GET http://localhost:8000/v1/ingest/jobs/job_01j7q3b2x1k5m8n9 \
  -H "Authorization: Bearer sk-live-prod-key"
```

### Response Example (200 OK)

```json
{
  "job_id": "job_01j7q3b2x1k5m8n9",
  "status": "completed",
  "total_documents": 1,
  "processed_documents": 1,
  "progress_percent": 100.0,
  "created_at": "2026-10-19T04:20:00Z",
  "completed_at": "2026-10-19T04:20:02Z",
  "error": null
}
```
