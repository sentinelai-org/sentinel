Sentinel LLMOps Gateway

Sentinel is a production-grade LLMOps gateway and agent platform engineered for high reliability, zero-cost resilience, and full operational observability.

Key features include caching, LangGraph RAG, and an LLM Router with local Ollama fallback.

Passerelle LLMOps Sentinel

Sentinel est une passerelle LLMOps et une plateforme d'agents de qualité production, conçue pour une haute fiabilité, une résilience à coût nul et une observabilité opérationnelle complète.

Les fonctionnalités clés incluent la mise en cache, un agent RAG LangGraph et un routeur LLM avec un repli local Ollama.
